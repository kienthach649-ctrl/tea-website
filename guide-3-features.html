🎨 Hướng Dẫn Sử Dụng 3 Tính Năng Mới

Tùy Chỉnh Thiệp Tặng Quà của Bạn

📸 Tính Năng 1: Upload Ảnh

Sử dụng hình ảnh của riêng bạn làm nền cho thiệp tặng!

1
Nhấn nút "📸 Upload Ảnh"
Khi bạn nhấn nút này, một cửa sổ chọn file sẽ mở lên.
2
Chọn file ảnh từ máy tính
Bạn có thể chọn bất kỳ ảnh nào (JPG, PNG, GIF, v.v.)
3
Xem ảnh xuất hiện trên thiệp
Ảnh sẽ tự động hiển thị làm nền của thiệp. Chữ sẽ hiển thị màu trắng để dễ đọc.
4
Lưu hoặc Xuất
Nhấn "💾 Lưu" để lưu template này, hoặc "📤 Xuất" để tải file JSON.
Ví dụ: Bạn có thể dùng ảnh cưới, ảnh gia đình, ảnh phong cảnh, hoặc bất kỳ ảnh nào bạn thích để làm thiệp độc đáo!
💡 Lưu Ý: Ảnh sẽ được lưu trong bộ nhớ của trình duyệt (LocalStorage) cho đến khi bạn xóa cache trình duyệt.

📄 Tính Năng 2: Upload File JSON

Import template được thiết kế sẵn hoặc từ bạn bè chia sẻ!

1
Nhấn nút "📄 Upload JSON"
Mở cửa sổ chọn file, tìm file JSON của template.
2
Chọn file JSON
File phải có định dạng đúng với các trường: title, bgColor, bgColor2, textColor, topEmoji, bottomEmoji
3
Template được áp dụng ngay
Thiệp sẽ cập nhật theo template từ file JSON.
Format JSON đúng:
{ "title": "Tết 2026", "bgColor": "#FF0000", "bgColor2": "#FFD700", "textColor": "#FFFFFF", "topEmoji": "🎆", "bottomEmoji": "🧧" }
✅ Chúng tôi đã chuẩn bị 2 file template ví dụ cho bạn:
  • template-example-tet.json - Template cho Tết 2026
  • template-example-valentine.json - Template cho ngày Valentine
💡 Lưu Ý: Bạn có thể chia sẻ file JSON với bạn bè, họ có thể import template của bạn chỉ bằng vài click!

✏️ Tính Năng 3: Chỉnh Sửa Template Tùy Chỉnh

Tạo template riêng của bạn với màu sắc, emoji, và tiêu đề tùy ý!

1
Nhấn nút "✏️ Chỉnh Sửa"
Form chỉnh sửa sẽ xuất hiện với 6 trường input.
2
Điền các thông tin:
  • Tiêu Đề: Tên của template (VD: "Sinh Nhật Vui Vẻ")
  • Màu Nền: Chọn màu chính (click vào ô màu)
  • Màu Nền 2 (Gradient): Chọn màu phụ cho gradient
  • Màu Chữ: Chọn màu cho text
  • Emoji Trên: Emoji ở trên (VD: 🎉)
  • Emoji Dưới: Emoji ở dưới (VD: 🎂)
3
Nhấn "👁️ Xem Trước"
Template sẽ cập nhật ngay để bạn xem kết quả trước khi lưu.
4
Lưu hoặc Xuất
Nhấn "💾 Lưu" để lưu vào máy, hoặc "📤 Xuất" để tải JSON.
Ví dụ:
Tiêu Đề: Chúc Mừng Năm Mới Màu Nền: #FF6B6B (Đỏ) Màu Nền 2: #FFE66D (Vàng) Màu Chữ: #FFFFFF (Trắng) Emoji Trên: 🎊 Emoji Dưới: ✨
💡 Lưu Ý: Bạn có thể chỉnh sửa bao nhiêu lần tùy ý. Các thay đổi sẽ được xem trước ngay lập tức.

📋 Quy Trình Hoàn Chỉnh

1️⃣
Chọn / Tạo Template:
Upload ảnh, upload JSON, hoặc chỉnh sửa tùy chỉnh
2️⃣
Xem Trước (Preview):
Thiệp sẽ cập nhật theo template bạn chọn
3️⃣
Viết Lời Nhắn:
Nhập lời nhắn, tên người nhận, tên bạn
4️⃣
Thêm Vào Giỏ Hàng:
Nhấn "Thêm Vào Giỏ Hàng" và tiến hành đặt hàng

🔧 Khắc Phục Sự Cố

❌ Nút Upload không hoạt động?
  • Hãy kiểm tra xem đã chọn đúng loại file (ảnh cho upload ảnh, JSON cho upload JSON)
  • Thử refresh lại trang (F5 hoặc Ctrl+R)
  • Kiểm tra xem trình duyệt có hỗ trợ FileReader API không (Chrome, Firefox, Safari, Edge)
❌ Template không thay đổi?
  • Hãy nhấn "👁️ Xem Trước" sau khi chỉnh sửa để áp dụng thay đổi
  • Kiểm tra xem đã chọn đúng template không (nút template phải bị highlight)
❌ File JSON không được import?
  • Hãy kiểm tra format JSON (phải có: title, bgColor, bgColor2, textColor, topEmoji, bottomEmoji)
  • Không nên edit JSON file bằng Word, dùng Notepad hoặc editor khác
  • Có thể dùng file ví dụ để test (template-example-tet.json)
