Khi bạn push code, tất cả các bước tiếp theo diễn ra tự động! 🎉

📍 Bước 1: Tạo GitHub Repository

  1. Truy cập: https://github.com/new
  2. Điền Repository name: tea-website
  3. Chọn Public ✅
  4. Click Create repository
✅ Thành công khi: Bạn thấy trang repository với URL như https://github.com/YOUR-USERNAME/tea-website

📍 Bước 2: Push Code lên GitHub

Mở PowerShell hoặc Git Bash và chạy các lệnh sau:

cd f:\webkinhdoanhso git remote add origin https://github.com/YOUR-USERNAME/tea-website.git git branch -M main git push -u origin main
⚠️ Lưu ý: Thay YOUR-USERNAME bằng username GitHub của bạn
✅ Thành công khi: Thấy message Branch 'main' set up to track remote branch 'main' from 'origin'

📍 Bước 3: Thêm FTP Credentials

3.1 Lấy FTP Information từ BKNS

Đăng nhập vào BKNS Dashboard và ghi lại:

Thông Tin Ví Dụ Ghi Chú
FTP_HOST ftp.kinhdoanhso.io.vn Hoặc IP address
FTP_USERNAME kinhdoanhso Username FTP
FTP_PASSWORD •••••••• Password FTP
FTP_REMOTE_PATH /public_html Public HTML folder

3.2 Thêm Secrets vào GitHub

  1. GitHub → Repository của bạn
  2. Click Settings tab
  3. Bên trái → Secrets and variables → Actions
  4. Click New repository secret
  5. Thêm 4 secrets (xem bảng trên)
⚠️ Bảo Mật: Không bao giờ commit FTP password vào Git! GitHub Secrets sẽ mã hóa tất cả.

🚀 Kích Hoạt GitHub Actions

Workflow file (.github/workflows/deploy.yml) đã tạo sẵn.

Test Deploy Lần Đầu

cd f:\webkinhdoanhso echo "✅ Test deploy" > test.txt git add . git commit -m "Test: GitHub Actions deployment" git push origin main

Theo Dõi Deploy

  1. GitHub → Repository → Actions tab
  2. Chấp nhận workflow chạy
  3. Chờ hoàn thành (xanh ✅ hoặc đỏ ❌)
  4. Nếu ✅, truy cập https://kinhdoanhso.io.vn
✅ Thành công khi: Website cập nhật tại kinhdoanhso.io.vn

💾 Update Thường Xuyên

Sau khi setup xong, mỗi update chỉ cần 3 lệnh:

cd f:\webkinhdoanhso git add . git commit -m "Update: [mô tả thay đổi]" git push origin main

GitHub Actions sẽ tự động deploy! Không cần FTP thủ công. 🎉

✅ Checklist Hoàn Thành

  • Tạo GitHub account (nếu chưa có)
  • Tạo GitHub repository: tea-website
  • Lấy FTP credentials từ BKNS
  • Push code lên GitHub
  • Thêm 4 FTP secrets vào GitHub
  • Test deploy lần đầu
  • Xác nhận website cập nhật tại kinhdoanhso.io.vn

❓ Câu Hỏi Thường Gặp

❓ Phải thêm FTP password vào GitHub không?
Có, nhưng qua GitHub Secrets (mã hóa). Không bao giờ commit password vào Git!
❓ Mỗi khi sửa code phải push lên GitHub?
Đúng! Đó là best practice. GitHub cũng serve như backup online. Ngoài ra, GitHub Actions sẽ tự động deploy khi push.
❓ Workflow chạy lâu không?
Bình thường 1-2 phút. Nếu lâu hơn, có thể do files nhiều hoặc network chậm.
❓ Làm sao nếu GitHub Actions fail?
Kiểm tra logs trên GitHub Actions tab. Thường là FTP credentials sai hoặc host không đúng.
